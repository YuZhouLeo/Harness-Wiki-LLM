F1

毛玻璃×便當盒

Glassmorphism × Bento Grid

淺色的柔彩背景上鋪一張便當盒格線，每一格是一片霧面玻璃，只裝一件事；顏色用來分課程，不用來裝飾。

從兩個風格各拿什麼

  • W04 玻璃擬態：半透明底、背景模糊、白色亮邊、頂部高光。
  • W05 便當盒佈局：模組化格線、每格一件事、格子大小代表份量。
  • 沒有拿的：深色漸層、山景、光帶動畫、圖片格。

字型

只用系統字型：PingFang TC／Microsoft JhengHei；大數字用 Segoe UI／SF Pro Display。不連 CDN，匯出 PDF 時不會掉字型。內文 14.5px（約 11pt）。

色票（每個顏色綁一件事）

  • 策略管理 #1d5fb8
  • 日本史 #b8401d
  • 日文寫作 #2b6b3d
  • 社團 #6a45b0
  • 作業 #855600
  • --ink #1b1d2a
  • 紙 #f3f2fa
  • 背景四個柔彩

關鍵做法

  1. 紙寬 182mm、左右留白 8mm，與 @page 相同（內容寬 166mm），裡面是 6 欄格線；格子只用 2、3、4、6 欄四種寬度，螢幕上的換行跟 PDF 一致。
  2. 玻璃格：background: rgba(255,255,255,.6)、backdrop-filter: blur(16px) saturate(160%)、1px 白邊、inset 0 1px 0 #fff。背景是五個柔彩 radial-gradient，沒有圖片。
  3. 列印是無縫直式：@page { size: 182mm 243mm; margin: 4mm 8mm 4mm }、六個邊界框給空字串、不印頁碼，給 iPad 直拿、GoodNotes 垂直捲動。格線照留；長的格子（有詞條、時代軸、作業清單的）文字可以跨頁，格子在頁尾斷成上下兩段、下一頁接著同一格；矮格子與格子裡的小格（詞條一列、步驟方塊、時代一列、作業一項、手寫區）break-inside: avoid。不再為了整格不拆把整列往下一頁推，頁尾不會空出半頁。頁面白底，玻璃改成淡紫灰實心格（#f5f4fb），拿掉 backdrop-filter 與陰影，PDF 不會出現點陣化的色塊。
  4. 每格左上一個色點加標籤（.kicker），色點、詞條、大數字都吃同一個 --c，換課程只改一個變數。
  5. 手寫區是畫了橫線的空格，橫線用 inline SVG（不用 CSS 漸層，PDF 放大才不會糊），作業前面留方格，直接在 GoodNotes 上打勾。
