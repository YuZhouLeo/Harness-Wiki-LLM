古代律令制
國家的建構

－大和時代飛鳥時期（大化改新）、奈良時代－

上一堂課停在飛鳥時期的推古朝新政：理念喊出來了（以天皇為中心的中央集權國家），但沒落實。這堂課講的就是「落實」的過程——從 645 年的大化改新開始，日本用兩、三代人的時間把唐朝那一整套律令制搬進來，變成一個有法典、有官僚、有戶籍、有稅制、有常備兵的國家；接著 710 年遷都平城京，進入奈良時代，看這套制度運作起來長什麼樣、又怎麼開始鬆動。

01

本堂因果鏈

照編號順序讀。

  1. 推古朝喊出「以天皇為中心的中央集權」，但蘇我氏坐大、社會階層矛盾嚴重，理念沒落實
  2. 645 年中大兄皇子與中臣鎌足除掉蘇我氏，孝德天皇即位，改元大化，遷都難波宮
  3. 頒布「改新之詔」：公地公民、二官八省與國郡里、戶籍與班田收授、租庸調
  4. 制度全面仿唐（618 年建國的唐朝），但法制真正完成要等到律令頒布之後
  5. 663 年白村江之戰敗給唐・新羅，日本退出朝鮮半島，改在北九州設防人與山城
  6. 對外收縮、對內強化，同時靠遣唐使繼續吸收中國制度與文物
  7. 710 年遷都平城京（仿長安），進入奈良時代
  8. 佛教被國家收編為「鎮護國家」的工具：東大寺＋國分寺體系　下週
  9. 收編過頭，僧人道鏡差點篡位（宇佐八幡宮神託事件）→ 794 年遷都平安京，逃離奈良佛教勢力　下週

02

總論：645 年，大化改新

不是一年做完的一場改革，是 645 年起陸續推出的一整串。

講義

○645，仿唐（618年）強盛＆ 社會階層矛盾嚴重、蘇我氏跋扈等問題；旨在建設中央集權國家。

紅圈＝課堂填空的答案

為什麼要改：兩邊的動機

  • 外面　唐朝 618 年建國後極為強盛（盛唐），日本想照抄一套成功的制度。 仿唐
  • 裡面　7 世紀前半土地兼併嚴重，豪族佔走大量土地，底層百姓淪為佃農甚至奴隸；加上蘇我氏專權跋扈。
  • 目標　推古朝喊過、卻沒做到的那句話：建立以天皇為中心的中央集權國家。
老師

★ 在古代社會，你沒有土地基本上就失去了生存的資格——土地是一個家庭、一個人最重要的生活工具。〔1-02:53〕

講義

律（刑罰法規）、令（行政法規）。

※645年頒布「改新之詔」，但法制的建構是在律令制定後才完成。

律令是兩種法

  • 律＝刑法　犯了什麼罪、判什麼刑。日本的律幾乎照搬唐律。 仿唐・律典
  • 令＝行政法　政府怎麼組織、官怎麼設、稅怎麼收。令依日本國情改寫較多。
  • 645 年只是頒了一份「施政方針」，還不是法律；寫成可執行的條文要等到大寶律令、養老律令。
老師

實際上改革是 645 年之後陸續推出的，不是一次做完。不過考試還是跟著教科書走，起點寫 645 年。〔1-01:43〕

補充

668 近江令（存疑）→ 689 飛鳥淨御原令 → 701 大寶律令（律令完備，首部真正施行的）→ 718 編成、757 施行的養老律令。

645 年的政變本身叫乙巳之變；「大化改新」指政變之後展開的一連串改革。

主力：誰做的

大化改新的人事表：招牌、引擎、幕僚，和被清算的人。

講義

○主力：孝徳天皇（36）；中大兄皇子（→天智天皇，38）＋內臣－中臣鎌足（→藤原，平安時代貴族的始祖） vs. 蘇我氏。左、右大臣－舊豪族。 國博士－遣隋、遣唐使。

○年號：大化（第一個年號）；遷都難波宮（大阪）；為了遠離蘇我氏等豪族及出港方便。

檯面上的招牌

  • 開始使用年號，第一個年號就叫「大化」。
  • 老師：中臣鎌足本來想找他合作，但覺得他不夠勇猛、有點軟弱，才改找中大兄皇子。〔1-05:31〕

中大兄皇子 → 天智天皇，第 38 代

引擎
  • 當時是皇太子，真正推動改革的人。
  • 和中臣鎌足聯手暗殺蘇我入鹿。
  • 663 年的白村江之戰是同一個人的後半場。

中臣鎌足 → 藤原

內臣
  • 內臣＝天皇旁邊的重臣、參謀，主要管軍事相關的事務。
  • 去世前，天智天皇賜姓「藤原」。
  • 藤原氏靠這套制度成為平安時代最大的貴族。

vs. 蘇我氏

被清算
  • 蘇我蝦夷讓兒子蘇我入鹿專政，滅掉聖德太子之子山背大兄王一族。
  • 入鹿被暗殺；隔天蝦夷知道大勢已去，在家自殺。
  • 前提：先把蘇我氏排除掉，改革才做得下去。

用舊勢力推新制度

  • 左、右大臣　都由舊豪族出任，避免推動新改革時遭既有勢力反撲。

顧問：國博士

  • 用了旻（留學僧）與高向玄理（留學生），兩人都是跟著遣隋使小野妹子入隋的隨行者。

遷都難波宮

  • 在大阪、面臨大阪灣。遷都原因：遠離奈良當地蘇我氏等豪族的殘餘勢力；持續派使節到中國，出港方便。
補充

孝德天皇是中大兄皇子的舅舅。中大兄皇子政變後沒有立刻即位，668 年才登基為天智天皇。

蘇我氏世系：稻目 → 馬子 → 蝦夷 → 入鹿。

甲講義｜史料卡

私地私民制改成公地公民制；舊豪族給予食封（俸祿）。

土地與人民歸誰：公地公民

  • 以前土地和人民是豪族的私產（私地私民），現在名義上全部收歸天皇（國家）所有。
  • 豪族必然反抗，所以給「食封」（俸祿），性質類似賠償金。等於把「地主」改造成「領薪水的官」。
  • 這是丙、丁兩條的地基：國家先擁有土地和人，才有資格編戶籍、分口分田、收租庸調。
補充

食封（じきふ）／封戶：指定若干戶人家，把他們該繳的租稅撥給某位貴族或官員。豪族拿到的是「收益」，不是「所有權」。

vs. 特權－上級官員、寺廟或神社 →貴族、莊園、僧兵。

※身分制：天皇、皇族→ 良民（上級官員＝貴族、下級官員、公民等）→ 賤民。

  • 先編戶籍，再按戶籍班田：每個滿六歲的良民與賤民分到一塊「口分田」；人死了田收回國家，六年一次重新分配。

身分制

  1. 天皇、皇族
  2. 良民　上級官員（五位以上，會發展成貴族）・下級官員・公民（農民與手工業者）
  3. 賤民　陵戶・官戶・公奴婢・家人・私奴婢。原則上「民有」的地位不如「官有」的；分到的口分田比良民男性少。

蔭位制：父祖的官位「蔭」到子孫

父祖嫡子庶子
官階高從五位下正六位上
只是從五位（上級官員最低階）從八位上從八位下

父祖只是從五位的，孫輩甚至沒有位階可敘。蔭位制學自中國，但日本符合資格的人範圍比中國窄、子孫敘位卻相對較高 → 貴族比例小、格外重視家族血緣。藤原家是最好的例子。

老師

★ 三位以上官員的後代，等於「起跑點已經不在起跑點上」。〔2-05:06〕

「位」是官階，從一位到初位共三十階；五位是關鍵門檻。唐朝的門蔭制要三品以上才蔭得到子孫，日本降到五位。

筆記｜改新之詔
05

白村江之戰與遣唐使

打輸之後對外收縮、對內強化；遣唐使變成單純去取經。

講義

※663天智天皇－白江口之戰（白村江之戰）、日本・百濟 vs. 唐・新羅。「東夷小帝國」。

設山城（北九州、瀨戶內海沿岸），防唐朝與新羅來犯。

663年　白村江之戰，日本戰敗
日本・百濟vs.唐・新羅
  • 背景　百濟 660 年被新羅所滅，遺民向交好的日本求援；新羅則向唐朝求救出兵。
  • 東夷小帝國　對中國採朝貢貿易、學習文物制度，卻沒有向中國稱臣，希望在東方另立一個與唐朝分庭抗禮的小帝國。
  • 戰後　擔心新羅、唐朝來犯，在北九州、對馬及瀨戶內海沿岸設山城、設瞭望臺。這也是防人須戍守三年的原因。
老師

★ 課本用語是「白江口之戰」，正式名稱應該是「白村江之戰」。〔2-14:37〕

奈良時代：平城京

710 遷都平城京 → 794 遷都平安京。兩個時代的分界看首都在哪。

講義

○710～794，平城京（奈良）→794，平安京（京都），平安時代。　○平城京（仿長安城）

・朱雀大路（右京＋左京＆外京）；條坊；大內裏（＝平城宮）；東、西市（官營市場）。

  • 大內裏＝平城宮。城北正中央，天皇與官員辦公起居的地方，對應長安城的宮城。
  • 條坊棋盤格的街道。縱向稱「坊」（一坊到四坊），橫向稱「條」（一條到九條）。
  • 朱雀大路貫穿條坊中央的南北大道，直通大內。
  • 左京・右京以平城宮面向朱雀大路的方向來分，所以看平面圖會覺得左右相反。
  • 外京長安城沒有。裡面有東大寺、興福寺等多座寺廟。
  • 東市・西市兩處官營市場，不是每天開。
  • 和長安比長安城東西較寬、南北較窄，平城京相反（東西窄、南北長）；道路都呈棋盤狀。
老師

據學者推測，興福寺是當時最有權勢的藤原家的氏寺（家族寺廟），附近的莊園也是藤原家的領地。〔2-33:18〕

平城京人口估計高達十萬人左右，其中豪族、貴族只有數百人。住得離大內越遠（條數越大，像八條、九條），身分地位就越低。〔2-34:33〕

老師

平城京位在盆地又沒有下水道，只能挖井取水、挖側溝排水，結果污水反而流向天皇所在的大內一帶。排水不良後來也成為遷都的原因之一。〔2-36:04〕

  • 講義　南都七大寺（東大寺等平城京附近寺廟），重學理研究，被禁止向民眾傳教。

記住三件事

每一節三件。記起來的在方格打勾。

總論

  • 645＝改新之詔頒布年，教科書以此為大化改新起點；但改革是陸續推出的。
  • 動機兩邊：唐朝強盛（想抄）＋國內土地兼併與蘇我氏跋扈（不得不改）。
  • 律＝刑法、令＝行政法；法制真正完成要到大寶律令、養老律令。

主力

  • 檯面上是孝德天皇（36），引擎是中大兄皇子（→天智天皇，38）＋內臣中臣鎌足（→藤原）。
  • 前提是先清算蘇我氏：入鹿被殺、蝦夷自殺，蘇我家專制瓦解。
  • 大化＝日本第一個年號；遷都難波宮＝躲豪族＋方便出海。

改新之詔 甲・乙

  • 甲＝公地公民（土地人民收歸國有），豪族拿食封當補償。
  • 乙中央＝二官八省：太政官（政治）＋神祇官（祭祀）並列，這是日本特色；痕跡留到今天的是大藏省、宮內廳。
  • 乙地方＝國郡里三層，國司中央派、郡司里長用地方豪族；九州另設大宰府；全國分畿內＋七道。

改新之詔 丙・丁

  • 丙：戶籍 → 班田收授 → 口分田（六年一班，仿唐均田制）；但特權田開了後門，長出莊園與僧兵。
  • 蔭位制＝父祖官位蔭到子孫，日本版比唐朝更有利於世襲，這是日本貴族社會與藤原氏的制度根源。
  • 丁：租庸調＋歲役雜徭＋軍團衛士防人；663 白村江戰敗（東夷小帝國的代價）→ 北九州設山城、派防人。

遣唐使

  • 630～894，目的是取經（情勢＋文物），對唐只朝貢、不稱臣。
  • 三條航線：北路（沿半島，最安全）→ 南路、南島路（半島局勢變了只好橫渡外海）。
  • 約二十次嘗試、十六次成功；一團可達五、六百人，翻船多半因為超載。

奈良時代

  • 710 平城京（奈良時代）→ 794 平安京（平安時代），分界看首都。
  • 平城京仿長安但東西窄、南北長；零件＝大內裏＋條坊＋朱雀大路＋左京右京＋外京（長安沒有）＋東西市。
  • 左京右京以大內裏朝南的視角分（看地圖會覺得相反）；外京裡的興福寺是藤原氏氏寺（學者推測）。

編輯拼貼年表

Editorial × Collage

用雜誌的明體大標、導言、分欄與細線排正文，再把講義原文、老師的話、補充各做成一種紙片貼上去；看紙片的顏色就知道這一句是誰說的。

從兩個風格各拿什麼

  • W03 雜誌編輯風：明體大標、首字放大的導言、3px＋1px 雙線欄頭配斜體編號、欄間 1px 細線、圖說式小字。
  • W18 拼貼風：紙膠帶貼住的史料卡、轉 0.7–1.3 度的便條、撕邊牛皮紙、方格紙、紅筆圈、螢光筆。
  • 沒有拿的：照片與靜物圖、整頁紙紋、手寫毛筆大標、壓花與郵票、導覽列。

字型

只用系統字型。內文黑體 PingFang TC／Microsoft JhengHei 14.5px；明體 Songti TC／PMingLiU 只用在大標、欄頭、年份與史料卡的甲乙丙丁；老師的話用楷體 BiauKai／DFKai-SB 16px；數字與編號用 Georgia。

  • 老師口述、紅筆 #b5271d

  • 補充的標籤字 #7a4e12

  • 虛線＝本堂沒講 #4f6157

關鍵做法

  1. 紙寬 182mm、左右留白 8mm，與 @page 的邊界相同（內容寬 166mm），螢幕上的換行跟 PDF 一致。螢幕上正文每一節是一列 grid-template-columns: 1fr 32mm，右邊 32mm 是畫了 19px 淡格線的筆記欄；列印時改單欄，筆記欄變成每節結尾一格 24mm 高的方格紙。格線是 inline SVG 的 <line> 加 <use> 重複，用漸層鋪的格線在 PDF 裡會糊掉或缺線。
  2. 紙片 .pin：紙畫在 ::after（底 #fffdf8、1px 細框、box-shadow: 2px 3px 0 不模糊），膠帶是 ::before 一塊 68×18px 色塊、用 clip-path 切出鋸齒兩端；整片 transform: rotate() 不超過 1.3 度。盒子上緣留 12px、下緣留 6px，膠帶、陰影、轉出去的角都在盒子裡，分頁時不會有一截留在隔壁頁。膠帶換色就換來源。
  3. 補充是牛皮紙色塊，下緣用 clip-path: polygon() 切成撕邊，不加框、不加膠帶。
  4. 紅筆圈是一條 inline SVG 路徑，preserveAspectRatio="none" 撐滿那個詞，vector-effect: non-scaling-stroke 讓線寬不變形；螢光筆是 box-shadow: inset 0 -.6em 0 的實心色塊（漸層在部分 PDF 閱讀器會畫成一條細線）。
  5. 史料卡橫放一整條（甲乙丙丁在左、原文在右），解說在下面分兩欄加欄間細線。表格不包捲動容器，讓字自動換行。
  6. 年表每列四格：年份、事件、出處、42mm 的空格；空格底部畫一條線給手寫。
  7. 列印是無縫直式、白底：@page { size: 182mm 243mm; margin: 4mm 8mm 4mm }，六個邊界框給空字串、不印頁碼。兩欄版面一律改單欄；紙片、牛皮紙、虛線框、條列都可以跨頁（跨頁的紙片斷成上下兩段，膠帶跟著第一行）；不拆的只有圖、表格列、年表列和小格子（時代軸、圖例、方格紙、組織圖、因果鏈的每一格），標題、欄頭、標籤 break-after: avoid。牛皮紙的撕邊在列印時改成蓋在底部的一條白色鋸齒，不用整塊 clip-path。
