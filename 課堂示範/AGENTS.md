# 我的講義規則

每踩一次雷就在下面加一行。`find-style` 會把版面規則寫到最下面。

1. 回覆用繁體中文（台灣用語）。
2. 內容只用 `原料/` 和 `母版/` 裡有的資料。沒有的寫「需要我提供」，不要自己補。
3. 產出存到 `產出/`，檔名寫主題，例：`講義-攝關政治.html`。
4. 用模板時只換內容，不重寫 CSS 和程式。複製模板用終端機指令，不要讀出來再整份寫回。
5. 要加外部套件前先告訴我，它要不要連網。

## 我喜歡的版面

- 單欄 A4；一頁一個文法點；頁首一條淡橘斜紋色帶放「Part 編號＋章名」，頁尾左下放頁碼。
- 標題三層：Lesson 小字＋大數字＋粗體標題；整條橘底白字圓角長條放小節標題；淡橘底「基礎練習」小標籤加粗體題目、下接虛線。
- 重點：淡橘底圓角框放「這些要記住」，每條 ✓ 開頭；關鍵詞用橘色粗體；句中重點用黃色螢光底；例句用底線標出對照處。
- 例句前放黑底小方塊，○ 表正確、× 表錯誤，錯句用灰字。
- 顏色：主色橘（約 #C8561E）、淡橘底（約 #FDEBDD）、重點色黃（螢光底）；內文黑、輔助灰。
- 表格：淡橘底表頭、細橘線框；填空用圓角空框，框內橘色圈號 ①②③。
- 答案：練習下方一行小字，「答案」「注」用橘色粗體標籤，不另開頁。
- 頁面最下方留圓角橘框「我的筆記」，內有橫線，約佔四分之一頁。
