# 學習地圖的資料格式（給 AI 看）

## 怎麼換內容

1. 複製 `模板/學習地圖.html` 到 `產出/`。
2. 打開副本，找 `id="map-data"`。它在 `<body>` 第一個節點，前後有 `內容開始`、`內容結束` 註解。
3. 只換這個節點裡的 JSON。不要改 JSON 後面的 CSS 與 JS。
4. 用瀏覽器打開。JSON 有錯時，頁面會顯示錯誤訊息。

## 寫內容的規則

- 只用使用者的原料。沒有資料的欄位就不寫，頁面不會留空框。
- 站數、主題數、題數都不限。程式會照 JSON 畫。
- 文字用 `**重點**` 標粗體。其他標記都不支援，HTML 會變成純文字。
- 內容不可出現 `</script>`。換行不要直接打在字串裡。

## 最上層欄位

| 欄位 | 必填 | 意思 |
|---|---|---|
| `title` | 是 | 地圖標題 |
| `stations` | 是 | 站的清單，順序就是路線順序 |
| `subtitle`、`eyebrow` | 否 | 副標；標題上方的小字 |
| `tagline` | 否 | 標題下方的短句清單 |
| `intro` | 否 | 首頁便條紙的一段話 |
| `card` | 否 | 產出卡，鍵是 `audience`、`goal`、`context`、`limits`、`tone`、`evidence`，各一句 |

## 每一站（`stations` 的一項）

| 欄位 | 必填 | 意思 |
|---|---|---|
| `name` | 是 | 站名，不可重複。進度靠站名記錄 |
| `when` | 否 | 時間或單元，例：`710～794`、`第 3 週` |
| `status` | 否 | `done` 已上過、`now` 上到這裡、`todo` 還沒上 |
| `group` | 否 | 大分類。同組同色，最多 4 色循環 |
| `short` | 否 | 頁首分頁籤用的短站名 |
| `summary`、`goal` | 否 | 一句話摘要；這站目標 |
| `remember` | 否 | 要記住的句子清單，每句可打勾。標題依句數變成「記住三件事」等 |
| `timeline` | 否 | `[{ "when", "event" }]`。首頁會合併成全部時間線 |
| `topics` | 否 | 主題講解的清單，見下表 |
| `quiz` | 否 | `[{ "q", "a", "options" }]`。`options` 是選項清單，可省略。答案預設看得到 |

## 每個主題（`topics` 的一項）

| 欄位 | 必填 | 意思 |
|---|---|---|
| `title` | 是 | 主題名稱 |
| `intro` | 否 | 開頭一句 |
| `flow` | 否 | 因果或步驟的短句清單，畫成箭頭鏈 |
| `points` | 否 | 重點清單，自動編號 |
| `table` | 否 | `{ "head": [...], "rows": [[...]] }`，每列第一格是列標題 |
| `note` | 否 | `{ "title", "text" }`，畫成便條紙 |
| `terms` | 否 | 名詞對照：`[{ "term", "original", "reading", "meaning" }]`，只有 `term` 必填 |

## 最小範例（2 站）

```json
{
  "title": "統計學學習地圖",
  "stations": [
    {
      "name": "平均數",
      "when": "第 1 週",
      "status": "done",
      "remember": ["平均數等於總和除以個數。"],
      "topics": [{ "title": "怎麼算", "points": ["先加總，再除以個數。"] }],
      "quiz": [{ "q": "2、4、6 的平均數是多少？", "a": "4" }]
    },
    { "name": "標準差", "when": "第 2 週", "status": "now" }
  ]
}
```
