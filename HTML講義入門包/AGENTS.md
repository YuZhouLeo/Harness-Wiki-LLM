# 我的講義規則

每踩一次雷就在下面加一行。`find-style` 會把版面規則寫到最下面。

1. 回覆用繁體中文（台灣用語）。
2. 內容只用 `原料/` 和 `母版/` 裡有的資料。沒有的寫「需要我提供」，不要自己補。
3. 產出存到 `產出/`，檔名寫主題，例：`講義-攝關政治.html`。
4. 用模板時只換內容，不重寫 CSS 和程式。複製模板用終端機指令，不要讀出來再整份寫回。
5. 要加外部套件前先告訴我，它要不要連網。
