# 做講義

1. 找內容：讀 `母版/`。沒有母版就先請學生跑 `make-master`；學生堅持不跑，才直接讀 `原料/`。
2. 選模板：
   - 學生指定的優先。
   - 否則看 `AGENTS.md`「我喜歡的版面」寫的最接近哪一種。
   - 還是沒有，就看內容：條列、年表、名詞用 `模板/講義-文史.html`；語言、一頁一個文法點用 `模板/講義-語文.html`；定理、例題、公式用 `模板/講義-數理.html`。
3. 用終端機複製模板到 `產出/講義-<主題>.html`（Windows 用 `Copy-Item`，Mac 用 `cp`）。不要讀出來再整份寫回。
4. 只改 `<!-- 內容開始 -->` 和 `<!-- 內容結束 -->` 之間的文字，換成母版的內容。模板裡的示範內容要全部換掉。
   - 一頁放不下，就複製一整個 `<main class="sheet">…</main>` 當下一頁。「我的筆記」只留在最後一頁。
   - 考點、關鍵字用模板原本的強調樣式，不另外發明顏色。
   - 數理的公式寫 `\( \)` 或 `\[ \]`。檔案要和 `產出/katex/` 放在一起。
   - 語文與數理的練習題，答案印在頁尾，不藏起來。AI 自己出的題目要標「AI 出的示範題」。
   - 母版的「我看不清楚的地方」和「核對清單」不要印進講義，只在回報裡說。
5. 如果 `AGENTS.md` 有「我喜歡的版面」規則：只改 `<style>` 開頭 `:root` 的顏色變數，或調整欄寬、標題樣式。版面要大改時先告訴學生，再改。
6. 核對：逐項看母版的「核對清單」，找不到的列出來，補進講義。
7. 回報 3 件事：
   - 檔案路徑與頁數估計。
   - 核對清單：共幾項、幾項找得到、哪幾項原本漏了。
   - 請學生做這 2 步：用 Chrome 打開檔案；隨機挑 3 個數字或名詞，翻回自己的原始筆記對一次。

匯出 PDF：Chrome 按 Ctrl+P（Mac 按 ⌘P），目的地選「另存為 PDF」，勾選「背景圖形」，邊界選「無」。
