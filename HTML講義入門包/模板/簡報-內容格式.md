# 簡報模板：內容格式（寫給 AI）

## 只能改哪裡
1. 把 `模板/簡報.html` 複製到 `產出/`，改複製的那份。
2. 只改 `<!-- 投影片開始：AI 只改這段 -->` 和 `<!-- 投影片結束 -->` 之間，再加上 `<title>`。
3. 不動標記之外的東西：提燈、`#d-slides`、CSS、`slide-editor`、`stage-engine`、`deck-effects`。翻頁和按 E 編輯都靠它們。例外只有 `#d-slides`，動法見最後兩段。
4. 只讀檔案前 150 行就夠，投影片段和所有版式範例都在裡面。

## id 規則
- 第 3 張：`<section id="s3" aria-label="短名">`，裡面的元件 `data-edit-id="s3-title"`。格式是 `s張號-部位`，整份不重複。短名會顯示在進度列。
- 每個要能改的文字元件都加 `data-edit-id`。沒加的字，學生按 E 改不到。
- 文字元件裡只放文字和 `<b>`，不再包另一個 `data-edit-id`。外框要包文字時，外框加 `data-edit="box"`（只能搬、縮放、刪除）。

## 5 種版式
**封面** `layout-cover`（標題 12 字內）
```html
<section class="slide layout-cover" id="s1" aria-label="封面">
  <p class="kicker" data-edit-id="s1-kicker">課名或單元</p>
  <h1 class="title" data-edit-id="s1-title">標題</h1>
  <p class="sub" data-edit-id="s1-sub">一句話說明</p>
  <p class="meta" data-edit-id="s1-meta"><b>日期</b>　2026-11-02</p>
</section>
```
**重點條列** `layout-points`（3～5 點，每點 40 字內）。後面每個 `.layout-*` 都有 `kicker`、`title`；`source` 可省略。
```html
<section class="slide layout-points" id="s2" aria-label="短名">
  <p class="kicker" data-edit-id="s2-kicker">小標</p>
  <h2 class="title" data-edit-id="s2-title">這張的結論（20 字內）</h2>
  <ol class="points"><li data-edit-id="s2-p1"><b>關鍵詞</b>　說明</li><li data-edit-id="s2-p2"><b>關鍵詞</b>　說明</li></ol>
  <p class="source" data-edit-id="s2-source">出處</p>
</section>
```
**左右對照** `layout-compare`（要強調的那欄加 `hot`；每欄說明 40 字內）
```html
<section class="slide layout-compare" id="s3" aria-label="短名">
  <p class="kicker" data-edit-id="s3-kicker">小標</p><h2 class="title" data-edit-id="s3-title">結論</h2>
  <div class="cols">
    <div class="col" data-edit-id="s3-left" data-edit="box"><h3 data-edit-id="s3-left-head">甲</h3><p class="lead" data-edit-id="s3-left-lead">一句重點</p><p data-edit-id="s3-left-text">說明</p></div>
    <div class="col hot" data-edit-id="s3-right" data-edit="box"><h3 data-edit-id="s3-right-head">乙</h3><p class="lead" data-edit-id="s3-right-lead">一句重點</p><p data-edit-id="s3-right-text">說明</p></div>
  </div>
</section>
```
**大數字或一句話** `layout-big`（數字 6 字內，單位放 `<small>`；一句話版 30 字內）
```html
<section class="slide layout-big" id="s4" aria-label="短名">
  <p class="kicker" data-edit-id="s4-kicker">小標</p><h2 class="title" data-edit-id="s4-title">結論</h2>
  <div class="bigbox"><p class="big" data-edit-id="s4-big">80<small>年</small></p>
    <div><p class="label" data-edit-id="s4-label">數字的意思</p><p class="note" data-edit-id="s4-note">補一句</p></div></div>
  <!-- 一句話版：整個 bigbox 換成 <p class="line" data-edit-id="s4-line">一句話</p> -->
</section>
```
**圖文** `layout-image`（2～4 點；圖放右邊就寫 `imgrow flip`）
```html
<section class="slide layout-image" id="s5" aria-label="短名">
  <p class="kicker" data-edit-id="s5-kicker">小標</p><h2 class="title" data-edit-id="s5-title">結論</h2>
  <div class="imgrow">
    <figure class="pic" data-edit-id="s5-pic" data-edit="box"><img src="圖檔相對路徑或 data URL" alt="圖的說明"><figcaption data-edit-id="s5-caption">圖說</figcaption></figure>
    <ul class="notes"><li data-edit-id="s5-n1"><b>關鍵詞</b>　說明</li></ul>
  </div>
</section>
```
圖要跟著單檔走：用 inline `<svg>` 或 data URL；學生也能按 E 再按「＋圖片」把圖內嵌。不連外部網址。

## 不要留產出卡
模板第 6 張 `layout-card` 是模板自己的說明。做學生的簡報時整張刪掉，不要放給觀眾看。

## 增減張數
1. 張數沒有上限，直接加或刪 `<section>`。程式會自己算張數、頁碼、場景和提燈路線，沒有地方要改總數。
2. 順序照原始碼的先後。重做整份時，張號照順序編；只加新張時，用沒用過的張號（例：s9 插在 s3 後面），舊 id 不改名。
3. 要一點一點講的元件加 `data-at="0"`、`data-at="1"`、`data-at="2"`。沒寫的元件一進這張就出現。

## 學生按 E 改過的內容
改動不在投影片段，存在 `#d-slides` 節點的 `edits`，鍵是 `data-edit-id`；載入時蓋過投影片段的文字。
1. 重做整份投影片之前，先問學生要不要保留手改的內容。
2. 不保留：把節點內容換回 `{"meta":{"rev":0,"saved_at":null,"schema":2},"edits":{},"assets":{},"notes":[],"overall":""}`。
3. 要保留：把 `edits` 裡的 `html` 抄進投影片段以後再清空，不然舊字會蓋掉新字。

## 學生貼修改清單給你時
學生按 M 標註元件，再按「複製給 AI」，就是貼給你的那份清單。標註也存在 `#d-slides` 的 `notes`。用搜尋找 `id="d-slides"`，不要整份讀，裡面可能有很大的圖。
1. 只改清單標到的元件，其他元件和共用 CSS 都不動。要改外觀就加在該元件的 `style`。
2. 找元件：有 `data-edit-id` 就用它；沒有就走「路徑」，從投影片 id 照 `nth-of-type` 往下找。
3. `edits` 會蓋過投影片段。清單的「edits 紀錄」寫了有的元件，要一併改那筆（`html`、`dx`／`dy`／`s`／`w`）或刪掉那筆，不然畫面不會變。JSON 裡的 `<` 寫成 `<`。
4. 改完：把處理過的標註從 `notes` 刪掉，`overall` 處理過就清空，`meta.rev` 加 1。
5. `notes` 裡沒有清單那幾則時，先請學生按存檔，再動手。

## 改完自查
1. 開檔，按 → 翻到最後一張，每張都看得到完整內容。
2. Console 出現「第 N 張內容太多」時，把那張拆成兩張。字多時程式會先自動縮字，縮到底才出現這句。
