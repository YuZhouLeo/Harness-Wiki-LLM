W04

玻璃擬態

Glassmorphism

在彩色或有景深的背景上疊半透明的霧面玻璃卡，靠背景模糊、亮邊與陰影做出前後層次。

關鍵特徵

  • 通透TRANSPARENT
  • 層次LAYERED
  • 通向更美好的未來A MORE BEAUTIFUL FUTURE

字型

英數 Outfit，中文 Noto Sans TC（Google Fonts），離線改用 PingFang TC／Microsoft JhengHei。字重只用 400、500、700，標題靠字級不靠裝飾。

色票

  • --deep #1b1a4a
  • --violet #5f4fc4
  • --pink #e29ac0
  • --sky #9fc0f2
  • --glow #ffd9a8
  • --ink #ffffff
  • --glass 白 13%
  • --edge 白 38%

關鍵做法

  1. 玻璃卡四件事缺一不可：半透明底（白 8–24% 的斜向漸層）、backdrop-filter: blur(18px) saturate(150%)、1px 白 38% 的亮邊、inset 0 1px 0 的頂部高光。
  2. 玻璃後面一定要有東西可以糊：多色漸層、光暈、山景。純色底上的玻璃看不出效果。
  3. 白字要壓在偏深的那一側：背景左側另外疊一層深色漸層（#shade），內文對比才夠。
  4. 卡片圓角 22px、膠囊按鈕 999px；陰影用背景色系的深紫，不用純黑。
  5. 場景用一張 inline SVG 畫（漸層天空、模糊的光帶、三層山），不放照片。

套到學校資料

適合課程總覽、學期儀表板這類一格一件事的頁面；數字、短句、標籤放在玻璃卡裡很好讀。

不適合長篇講義正文與要手寫的頁面：底色深、背景花，筆跡看不清楚。

要改用在 NCCU 交付物時換成淺色底、關掉光帶動畫，並在 @media print 拿掉 backdrop-filter（做法見 F1 毛玻璃×便當盒）。
