大和時代考前重點

古代天皇制的形成：古墳時期＆飛鳥時期

日本在西元 3 到 8 世紀之間，從「一個大王加一群地方豪族的聯盟」變成「以天皇為中心、有官僚制度的國家」。這一頁是前半段。

考點

○時代：3A.D.～710；遷都範圍侷限在以大和（現在的奈良）為中心近畿地區。

前期－古墳時期（3A.D.～6 A.D），後期－飛鳥時期（592-710）

古代　※古代：古代天皇制。

定義

大和時代將近五百年。都城一代一代搬，但都在奈良盆地一帶，沒離開過。

分期看的是「文化特徵」，不是政治事件：前期的標誌是古墳，後期的標誌是飛鳥文化，也就是最早的佛教文化。

老師

★ 從推古朝新政開始進入「古代」，在此之前叫「上古」。推古朝新政到大化改新，目標都是建立以天皇為中心的中央集權國家。

補充

592 年是推古天皇即位那年（崇峻天皇同年被殺）；710 年是遷都平城京。

記住三件事
  1. 大和時代＝古墳期＋飛鳥期，將近五百年，都城都在奈良一帶。
  2. 當時的君主叫大王；「天皇」和「日本」都是 7 世紀末才有的名字。
  3. 前期看古墳，後期看飛鳥（佛教）文化。

古墳時期：大和政權

3～6 世紀
考點｜政權長什麼樣

○大王＋氏族（豪族）。政權範圍：九州北部-中部地方。

※「天皇」稱號－7世紀後期天武天皇（40）。　※「日本」「日本史」？

定義

大王和各地豪族組成的聯盟，不是大王一個人說了算；大王比較像盟主。東北的蝦夷、九州南部的熊襲・隼人還不在裡面。

易混淆｜大王 ≠ 天皇

★ 這個時期還沒有「天皇」稱號，只有「大王」。大仙古墳被注成「仁德天皇陵」，是後世受戰前皇國思想影響的寫法。「日本」這個國名也是 7 世紀末才出現，在此之前中國史書叫這裡「倭」。

考點｜成立原因

1.魏晉南北朝、五胡亂華，中國對周邊控制減弱。

2.欲得中國或朝鮮技術、鐵。

→Ex：鐵器（七支刀）、製陶、紡織、漢字、儒家、佛教etc；主要由百濟傳入。

老師｜傳進來的東西，後來長成什麼
鐵器★ 七支刀是百濟王獻給倭王的。現藏奈良縣天理市的石上神宮；全長約 75 公分，是祭品不是實用品；銘文共 61 字。
漢字百濟的王仁博士帶來《論語》與《千字文》。在此之前日本史只能靠考古文物和中國史書。
儒家五經博士傳入五經（詩、書、易、禮、春秋）。漢朝以儒家選官僚 → 飛鳥時期的冠位十二階。
佛教百濟聖明王獻佛像、佛經給欽明天皇。對日本是新興宗教 → 朝廷分成擁佛派與排佛派。

★ 三國之中跟日本關係最好的是百濟，文物多從百濟來。

考點｜朝鮮半島

※朝鮮半島三國鼎立：高句麗、新羅、百濟。 cf. 任那（加羅諸國）。

※朝鮮移民-天皇祖先說。

定義｜位置示意

百濟西南。跟日本最好
新羅東南。跟日本打過仗
加羅諸國最南端，十幾個部落的聯盟

391 年百濟要求日本出兵打新羅，日本佔新羅王城約九年；400 年被高句麗擊退。六世紀左右加羅諸國被新羅滅掉。

天皇祖先說：帶著先進文物和技術的渡來人勢力最大，變成大王。到現在還是未被證實的說法。

易混淆｜任那＝加羅諸國

★「任那」是日本跟加羅結盟之後給的國號，只有日本在用；韓國稱加羅諸國。

考點｜中央政治制度

氏姓制度：氏－血統。姓－朝廷的地位和職務。世襲。

cf. 只有統治階層才有；大王及平民百姓無。

老師｜一個名字拆四段
藤原氏
血統
朝臣姓
朝廷的職務地位
九條苗字
分家後的家名
兼實名

★「藤原朝臣九條兼實」八個字。姓是大王賜的：有當官才有姓，所以一般民眾沒有；大王自己也沒有，因為沒有人賜給他。

易混淆｜氏・姓・苗字

大化改新之後氏姓制度廢除，表示身分的「姓」不再需要；氏與苗字合為一體，統稱苗字，也就是現在日文的「姓氏」。

一般民眾到明治維新才有姓氏；天皇家到今天都沒有姓氏，只有名。

考點｜古墳

○古墳：大王或各豪族墳墓。表權威。埴輪。

消失原因：群集墳（有力農民的家族墳），大王或各豪族重心轉移至蓋寺廟或佛像。

定義
  • 古墳：不是一般埋屍體的地方，蓋得雄偉是為了表示權威。近畿地區最多。
  • 大仙古墳：大阪府堺市，日本最大。
  • 前方後圓墳：前面方、後面圓，最常見的形狀。
  • 埴輪：排列在古墳底部或墳丘四周的陶製品總稱。形態有船、舞者、家屋、雞。
  • 陪葬品三類：咒術祭祀（銅鏡、勾玉、三角緣神獸鏡）、權力軍事（頭盔、盔甲）、陶器。沒有殉死。
  • 群集墳：很多規模變小的墳墓聚集在同一區，一個地方十個到一百個。
易混淆｜內部構造
豎穴式從上往下挖，下葬要打開上方。早期多。
橫穴式走道盡頭有門，方便追葬。晚期多。
老師

★ 古墳原本表示政治與社會身分 → 群集墳 → 單一墳墓，只剩埋葬遺體的功能。

群集墳重視的是家族支配；之後的官僚不再世襲，顯示的是個人支配。

記住三件事
  1. 政權是大王＋豪族的聯盟；官職靠出身（氏姓制度：氏＝血統，姓＝朝廷頭銜，世襲）。
  2. 鐵、漢字、儒家、佛教都經由百濟傳入，因為中國正亂、日本想要技術。
  3. 古墳＝權威象徵；後來變成群集墳，權威改由寺廟表現。

飛鳥時期：新政

6 世紀後期～710
考點｜飛鳥與大王家

※飛鳥：日本最早的寺廟－飛鳥寺，日本最早的佛教文化－飛鳥文化。

○6 A.D.後期～710　　※飛鳥（奈良縣南部）

○「大王家」（血緣）：蘇我氏＋欽明（29）。

定義

初期的大王，皇位繼承不一定跟血緣有關，很多時候是地緣或政治協商。「有大王家血緣才能繼位」是從這時候慢慢固定下來的。

當時還沒有嫡長子繼承制：天皇的弟弟、長子、次子都可能繼位。

老師

★ 六世紀，第 29 代欽明天皇娶了蘇我氏家長蘇我稻目的女兒，開始大王家與蘇我氏的姻親關係。

補充

稻目之子馬子 → 蝦夷 → 入鹿，三代掌權到 645 年的乙巳之變。

考點｜氏族對立

○氏族對立（蘇我氏：擁佛，財政 vs. 物部氏：排佛，軍事）→推古天皇（33。女性－中繼）。

蘇我氏擁佛・管財政
老師跟大王家關係密切
VS
物部氏排佛・管軍事
老師保守，排斥新興宗教
老師

★ 更根本的是政治鬥爭：一個國家最重要的就是管錢和軍事。

蘇我馬子滅了物部氏，同時把親物部的第 32 代崇峻天皇殺了。蘇我氏找不到有蘇我血緣的合適男丁，就推欽明天皇的女兒推古當第 33 代：日本史上第一位女性天皇。

定義｜中繼

沒有合適男丁時由女性擔任，性質是「中繼」。126 代裡女性天皇只有個位數。

推古是欽明的女兒、稻目的外孫女。

考點｜理念與主力

○理念－天皇為中心的中央集權國家。為時短，到大化改新才較落實。

○改革主力：蘇我氏 ＆聖德太子。

定義｜聖德太子

第 31 代用明天皇的兒子、推古天皇的侄子，跟蘇我家也有血緣。據說在馬廄出生，又稱廄戶皇子。

老師

背景是受到隔壁隋朝的刺激。新政時間很短，提出的理念要到大化改新才比較完整落實。

補充

隋在 589 年統一中國；推古朝新政（593 年起）正好在這之後。

考點｜三大政策 ①

・冠位十二階制－能力選官，十二階（儒家） ≠ 氏姓。

老師把冠分成十二階，每一階冠帽的顏色和裝飾不同。★ 採用儒家的德目：德、仁、禮、信、義、智，各分大小，所以是十二階。目的是打破氏姓制度的世襲，用能力取才。

補充603 年制定。冠色依序紫・青・赤・黃・白・黑。

考點｜三大政策 ②

・憲法十七條－官僚訓誡。以和為貴、重佛教、服從天皇。

老師★ 以和為貴：有鑑於之前地方豪族爭權奪利，要官僚不要再搞政治鬥爭。重視佛教：蘇我氏擁佛，聖德太子也很重視。服從天皇（＝服從大王）：這裡的官僚不是「國家的公僕」，而是天皇的官僚。

補充604 年制定。第一條「以和為貴」、第二條「篤敬三寶」、第三條「承詔必謹」。

考點｜三大政策 ③

・遣隋使（小野妹子etc），攝取中國文化。

「日出處天子致書日沒處天子無恙云云」(『隋書』「倭國傳」)。

老師據說至少派了五次。★ 遣隋使是去朝貢，但日本沒有向中國稱臣。★ 隋煬帝看了國書非常火大：中國皇帝認為只有自己是天子，你竟然也自稱天子。

老師航路刻意沿岸繞遠路，因為當時的船不堅固、海上風浪多變：

  • 大阪灣
  • 瀨戶內海
  • 關門海峽
  • 對馬海峽
  • 沿百濟沿岸
  • 山東半島登陸
  • 陸路到長安

補充有紀錄的遣隋使：600 年（只見於《隋書》）、607 年小野妹子、608 年、614 年。

易混淆｜這四個最常寫錯
憲法十七條不是現在講的國家基本大法，是對官僚的訓誡。
小野妹子是男的。第二次遣隋使的團長。
朝貢 ≠ 冊封老師日本去朝貢，但沒有向中國稱臣；朝鮮半島各國則受中國冊封。
補充朝貢＝向中國皇帝送禮，換回贈與貿易；冊封＝接受中國皇帝授予的王號、承認自己是臣屬。
冠位十二階 ≠ 氏姓冠位按能力授予個人，不世襲；氏姓靠出身，給家族，世襲。
記住三件事
  1. 蘇我氏（擁佛、管財政）打贏物部氏（排佛、管軍事），扶植第一位女天皇推古。
  2. 聖德太子與蘇我馬子推動三大政策：冠位十二階（能力取代出身）、憲法十七條（官僚聽天皇的）、遣隋使（學中國但不稱臣）。
  3. 目標是以天皇為中心的中央集權，真正落實要等 645 年後的大化改新。

佛教文化

飛鳥文化
考點

・最早佛教文化（飛鳥文化）。

・寺廟或佛像－大王或豪族權威象徵＆祈福（≒ 民間宗教）。Ext：飛鳥寺、法隆寺、四天王寺etc。

定義

飛鳥文化就是日本最早的佛教文化，當時留下的寺廟、佛像都在奈良。大王、豪族蓋寺廟和佛像是要展現權威，接替了古墳的功能；也把佛教當成祈福的工具，很多寺廟是發願、還願蓋的。

易混淆｜三座寺是誰蓋的、為什麼蓋
寺誰為什麼蓋記憶點
飛鳥寺蘇我氏蘇我氏發願所建日本最古老的私人寺廟，不是官方蓋的；有大佛
法隆寺聖德太子祈求父親用明天皇病癒又叫斑鳩寺。1993 年登錄世界遺產，是日本最早的世界遺產
四天王寺聖德太子蘇我氏與物部氏開戰時祈求打贏，打贏後還願在大阪，靠大阪灣；朱紅色，學者認為建造時受到中國寺廟影響
記住三件事
  1. 飛鳥文化＝日本最早的佛教文化，寺廟與佛像都在奈良。
  2. 寺廟接替古墳，成為展示權威的方式，也用來祈福、還願。
  3. 三座寺：飛鳥寺（蘇我氏）、法隆寺（聖德太子為父病）、四天王寺（聖德太子還願）。

F6

新粗野×重點框

Neo-Brutalism × 參考書重點框

一節一張粗黑框的卡，卡裡是參考書那種左上帶色塊標籤的重點框；一種框一個顏色，紅字是填空答案，黃色螢光筆是老師強調，卡的右邊留一條點格欄手寫。

從兩個風格各拿什麼

  • W09 新粗野主義：3px 黑框、6px 6px 0 不模糊的位移陰影、鮮明色塊標籤、黑底白字的編號方塊、標題壓在加框的色塊上、微微旋轉的標章。
  • 參考書重點框（L1）：標籤騎在框線左上角；一種框一個固定顏色與固定意思；講義原文加粗、填空答案紅字加底線；老師強調用黃色螢光筆；每節結尾「記住三件事」；頁首放圖例。
  • 沒有拿的：新粗野的插畫色塊堆疊、游標與笑臉貼紙、導覽列；參考書的深藍章節色塊（改成黑色編號方塊）。

字型

只用系統字型：PingFang TC／Microsoft JhengHei，內文 14.5px（約 11pt），講義原文 15.5px 粗體；編號方塊用 Segoe UI／SF Pro Display。不連 CDN，匯出 PDF 時不會掉字型。

色票（每個顏色綁一件事）

  • 考點（講義原文）--pt #ff8370
  • 填空答案的紅字 --pt-ink #cf1820
  • 定義 --def #8ec5ff
  • 老師 --tc #ffd92e；螢光筆 #ffe45c
  • 易混淆 --mix #ff9fdc
  • 補充 --ex #8fe3a6
  • 自我測驗與答案 --quiz #c4b0ff
  • 記住三件事、框線 --ink #111111
  • 紙 --paper #fffdf6

關鍵做法

  1. 重點卡 .card：border: 3px solid #111; box-shadow: 6px 6px 0 #111，無圓角；右邊留 6px 外距給陰影。卡頭是 34px 的黑底白字編號方塊加 21px 標題。
  2. 卡身兩欄 grid-template-columns: minmax(0,1fr) 118px：左邊放重點框，右邊是虛線隔開的點格欄給手寫；窄螢幕改成上下疊。
  3. 點格與橫線用 inline SVG 畫，不用 CSS 漸層鋪：手寫欄設 position: relative，裡面放 <svg class="dg">（絕對定位、寬高 100%，會跟著卡片長高）。點格是每 14px 一條直的 <line y2="100%">，stroke-dasharray=".01 13.99" 加 stroke-linecap="round"，一條線就是一排點；26 條線定義一次（#dg），各欄用 <use> 取用。橫線格是一條 stroke-width: 4000、stroke-dasharray: 1 28 的直線。用 radial-gradient 加 background-size 鋪的點格，在長頁 PDF 裡會被點陣化、放大是糊的。
  4. 重點框 .bx：2.5px 黑框，淡色底；標籤 .tg 騎在框線上，底色＝框的種類。框線與底色畫在 .bx::before（top: 13px 才開始），標籤用 position: absolute; top: 0，所以標籤落在 .bx 自己的盒子裡，分頁時不會被留在上一頁。換種類只換一個 class（pt／def／tc／mix／ex／quiz／three）。
  5. 紅字答案 .ans：color: #cf1820 加 2.5px 底線；螢光筆 .hl：box-shadow: inset 0 -.62em 0 #ffe45c，只蓋下半行，是純色塊（不用漸層，各家 PDF 閱讀器才畫得一樣）。
  6. 列印是無縫直式：@page { size: 182mm 243mm; margin: 4mm 8mm 4mm }，六個邊界框給空字串、不印頁碼。文字一律可以跨頁：重點卡、重點框都不設 break-inside: avoid，每頁填到底、下一頁接著同一句；卡與框跨頁時框線在頁緣開口，看起來是同一個框延續。不拆的只有切開就壞的小東西（卡頭、時代軸、因果鏈的格子、表格列、小圖解、測驗題、手寫橫線格）；卡頭設 break-after: avoid，重點框的標籤 .tg 在框自己的盒子裡，兩者都不會落單在頁尾。右側手寫欄的點格 SVG 會跟著卡片跨頁，每一頁都畫得出來。螢幕上的紙寬 182mm、左右留白 8mm，跟 @page 一樣；米白紙色只在螢幕上，印出來是白底。
  7. 自我測驗的空格 .blank：inline-block、寬 5.6em、高 34px、粗框加 3px 位移陰影，行高 2.5，可以直接手寫；答案集中在頁尾一張卡，不做「點了才顯示」。
  8. 「記住三件事」每一條前面是一個 16px 的粗框方格，背起來就打勾。

套到學校資料

適合考前重點、帶填空的講義整理：內容有講義原文、老師口述、補充、容易搞混的東西好幾種來源，要一眼分得出哪一句會考。

不適合只有一種資訊的頁面（純年表、純名單）：顏色用不上，只剩粗框會顯得吵，改用 F2。

規範符合 NCCU 製作規範：淺色底、無動畫、無 fixed／sticky、無 vh、系統字型、無縫直式分頁（182×243mm，文字跨頁接續，只有圖、表格列、小格子不拆；規格面板與工具列不進 PDF）。這一份印出來是 13 頁（每頁 182×243mm）。手寫區：每張卡右側的點格欄、測驗空格、加分題的橫線格。
