HTML 講義入門包

你負責備料、指定樣子、檢查內容。AI 負責把它做成講義、學習地圖和簡報。

先填喜好選單做出屬於你的呈現方式

喜好很難用嘴巴講，一張一張選比較快。講師的喜好也是這樣選出來的。

  1. 用 Chrome 打開 版面喜好選單/index.html。
  2. 每張範例選「喜歡」「留」或「不要」，至少選 3 個喜歡。想到什麼就寫在想法欄。徽章是講師的選擇，不想被影響就關掉開關。
  3. 填完頁尾「你的喜好卡」的 6 題。
  4. 下載 我的喜好.md，放進 範例/。
  5. 跑 find-style。AI 會讀喜好卡和你喜歡的範例，把規則寫進 AGENTS.md。
之後每次產出都會照這份規則。下次改變喜好，就再選一次，再跑一次 find-style。

去哪找版面

選單裡沒有喜歡的，就上網找。不用會形容，看到喜歡就存進 範例/。找 3 張。

順序去哪找怎麼做注意
1自己的參考書、老師的講義手機拍最喜歡的一頁最穩，樣子一定印得出來
2網路書店的試閱搜書名，找「試閱」或內頁預覽不是每本都有內頁
3圖片搜尋、Pinterest搜「數學 講義 排版」「歷史 筆記 版面」「study notes layout」常找不到出處，也常是沒印過的模擬圖
4Behance搜「editorial layout」「textbook design」看得到整本的版面結構
5Canva 範本搜「worksheet」當靈感，不用在 Canva 裡做
圖只讓 AI 看版面。別人的內容不要抄進你要分享的講義。

核對與匯出 PDF

外觀漂亮不代表內容是對的。這一步不能省。

  1. 看 AI 回報的核對清單：共幾項、漏了哪幾項。
  2. 隨機挑 3 個數字或名詞，翻回自己的原始筆記對一次。
  3. 用 Chrome 打開講義，按 Ctrl+P（Mac 按 ⌘P）。
  4. 目的地選「另存為 PDF」，勾選「背景圖形」，邊界選「無」。

標註給 AI指著元件說要怎麼改

「那個標題太大」AI 不知道是哪一個。指給它看。簡報模板內建這個功能。

  1. 用 Chrome 打開簡報，按 E 進入編輯模式。
  2. 按 M，或按工具列的「＋標註給 AI」。
  3. 點要改的元件，寫想法。例：「這個標題太長，改成一行」「這張卡片的底色換成淺灰」。
  4. 重複第 3 步，把要改的都標完。
  5. 按 Ctrl+S 存檔（Mac 按 ⌘S）。第一次存檔要選這個檔所在的資料夾，或它的上層。只有 Chrome、Edge 能寫回。
  6. 按「複製給 AI」，貼到 AI 對話欄送出。AI 只改標到的元件，改完會清掉處理過的標註。重新整理就看得到結果。
只想改字或搬位置：按 E 之後直接點字改、直接拖曳，不用標註。
講義和學習地圖沒有這個功能。請在對話裡寫清楚哪一段，例：「第二節的年表，把年份欄改窄」。

HTML 的 3 層打開 三層原理示意.html 看 60 秒動畫

層寫在哪管什麼像房子的要改這些就找它
骨架HTML有哪些東西：標題、段落、按鈕鋼筋和隔間字、順序、多一個框
外觀CSS長什麼樣：顏色、字級、間距、幾欄油漆和裝潢顏色、大小、排法
動作JavaScript按了會怎樣：翻頁、計分、存進度水電和開關按鈕的反應、測驗、動畫的開關

3 層通常都在同一個 .html 檔裡：<style> 裡是外觀，<script> 裡是動作，其他是骨架。

套件住哪一層

套件不是第 4 層，是別人寫好的骨架、外觀、動作。放進檔案的方式看得出它在哪一層：<link> 進外觀，<script> 進動作，貼一段 HTML 進骨架。

東西骨架外觀動作說明
配色●一組 CSS 變數
講義、報告版式●●整頁範例
簡報●●●含翻頁程式
按鈕、開關等小元件●●有的有Uiverse、VengeanceUI 的元件約半數要 JavaScript
animate.css●有的有動畫本身是 CSS；要「按了才動」才用 JavaScript
滾動、翻牌等互動效果●●●
KaTeX●●CSS 給字型，JavaScript 排公式
Chart.js、Mermaid、Rough.js●JavaScript 把資料畫成圖

你不用自己找程式碼。先判斷要動哪一層，再選下面的做法。

想改在哪一層怎麼做

HTML 和 AI 互相協助不只是 AI 做給你看

AI 不會點按鈕，你不會寫程式。HTML 可以當你們中間的介面，一輪一輪往前走：

  1. AI 做一份 HTML。
  2. 你在瀏覽器裡點、勾、寫。
  3. HTML 把你的選擇變成 .md 或 JSON。
  4. AI 讀這份檔，做下一版。
做法你做什麼AI 拿到什麼狀態
決策頁每題選一個選項你的答案清單講師做過，這堂課就是這樣定的
標註修改清單點元件、寫想法哪個元件要怎麼改講師做過，簡報模板內建
喜好選單挑喜歡的範例你的版面規則講師做過，入門包內附
按 E 改完再轉檔直接改簡報改過的內容講師做過
關聯圖看圖找漏洞哪些筆記沒連起來講師做過，資料由腳本算好，HTML 畫圖
錯題回饋寫測驗，下載錯題你錯在哪，再出相近的題目你也可以做
原文對照清單逐項打勾、標錯哪幾段要照原文改你也可以做

前端做不到的事

HTML 檔在你的瀏覽器裡執行。下面這些事要有後端（一台一直開著的伺服器）。AI 說做得到時，先問它要不要後端。

一定要後端

  • 多人共用同一份資料
  • 登入帳號
  • 藏 API 金鑰
  • 定時推播、寄信
  • 換裝置自動同步

常見誤解

把 API 金鑰寫進 HTML，以為別人看不到。其實所有人按 F12 都看得到。不要這樣做。

卡住了

狀況怎麼辦
打 / 或 $ 找不到 Skill確認打開的是 HTML講義入門包 這個資料夾，不是上一層。再不行就送「照 .agents/skills/…/SKILL.md 做」。
額度用完和旁邊同學一起看他的畫面，步驟照學。各家額度重設的時間不同，回家再繼續。
AI 說看不到圖改用文字跟它說版面，或直接用模板：「用模板/講義-文史.html」。
公式沒有排出來確認講義和 katex/ 資料夾都在 產出/ 底下，沒有被搬開。
AI 把模板改壞了刪掉 產出/ 裡那個檔，再跑一次指令。模板本身在 模板/，不會受影響。
內容被 AI 加料跟它說：「只用母版有的資料，把母版沒有的刪掉。」再在 AGENTS.md 加一行規則。

帶回家

  1. 每踩一次雷，就在 AGENTS.md 加一行。下次 AI 就不會再犯。
  2. 喜歡的成品存進 範例/，下次當範例。
  3. 喜好變了，就回 版面喜好選單/index.html 再選一次，再跑 find-style。
  4. 新的一科就複製一份整個資料夾，換掉 原料/。
  5. 想做到更細，打開 成品參考/，看講師的 3 份真品，也可以按 F12 看原始碼。
