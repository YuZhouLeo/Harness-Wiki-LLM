# 整理母版：先整理內容，再套版

1. 讀 `原料/`。學生有指定檔案就只讀那些；沒指定又有多份，先問要用哪幾份。圖或 PDF 讀不到就直接說。
2. 整理成 `母版/<主題>.md`，格式如下：

   ```markdown
   # <主題>

   ## 一句話：這份在講什麼

   ## <章節 1>
   - 重點（一句一件事）
   - 名詞：意思
   - 年代、公式、例句、例題照原文

   ## <章節 2>

   ## 我看不清楚的地方
   - <原文哪一句>：<為什麼不確定>

   ## 核對清單
   - <所有數字、年代、公式、人名、專有名詞，一行一個>
   ```

3. 遵守這 4 條：
   - 只整理，不新增。筆記沒寫的事不要補，你知道也不要補。
   - 順序可以調，意思不能改。數字、公式、例句一字不改。
   - 筆記有錯字、前後矛盾或字認不出來，不要默默修，寫進「我看不清楚的地方」。筆記只是寫得短、沒有展開，不算看不清楚，不要列。沒有就寫「沒有」。
   - 一章放不完就分節，不要刪內容。
4. 回報：分了幾章、核對清單幾項、有哪些看不清楚的地方。不用等學生回答，下一步一樣可以做 `make-handout`；學生之後要改再改。
