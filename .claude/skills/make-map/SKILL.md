# 做學習地圖

這個模板含程式。不要重寫，也不要整份讀出來再寫回；你只換一段 JSON。

1. 讀 `母版/` 和 `模板/學習地圖-資料格式.md`。沒有母版就先請學生跑 `make-master`。
2. 規劃分站：照時間、章節或由淺到深排，3～9 站。把分法用一句話告訴學生。
3. 用終端機複製模板到 `產出/學習地圖-<主題>.html`（Windows 用 `Copy-Item`，Mac 用 `cp`）。
4. 在複製出來的檔案裡，找到 `<!-- 內容開始` 和 `<!-- 內容結束 -->`。只換中間那個 `id="map-data"` 節點裡的 JSON。
5. 內容只用母版有的。沒有資料的欄位省略，不要留空字串，也不要編。AI 自己出的練習題要標「AI 出的示範題」。
6. 檢查 JSON 格式正確（括號成對、字串用雙引號）。
7. 回報：檔案路徑、幾站、每站名稱。請學生用 Chrome 打開，打勾一站，重新整理，確認進度還在。

進度只存在這台電腦的這個瀏覽器。換電腦不會跟著走，這是前端做不到的事（要後端）。
