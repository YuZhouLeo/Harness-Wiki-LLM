# HTML 講義入門包

你準備自己的筆記，AI 幫你做成講義、學習地圖和簡報。不用會寫程式，也不用背語法。

## 開始

1. 下載這個專案。按這頁綠色的 **Code**，再按 **Download ZIP**。會用 git 的人可以直接 `git clone`。
2. 把 zip 解壓縮到桌面。不要直接在 zip 裡面開檔案。
3. 用 Chrome 打開 `開始.html`。
4. 照 `開始.html` 的步驟裝好 VS Code 和擴充功能，再用自己的 AI 帳號登入。

在 VS Code 要打開 `開始.html` 所在的資料夾。打開上一層時，AI 找不到 Skill 和規則檔。

GitHub 網頁只顯示 HTML 的原始碼。要看畫面，請下載後用瀏覽器打開。

## 裡面有什麼

| 檔案或資料夾 | 內容 |
|---|---|
| `開始.html` | 操作說明：安裝、5 個指令、找版面、功能地圖 |
| `AGENTS.md`、`CLAUDE.md` | AI 的規則檔 |
| `原料/` | 放你的筆記；裡面有一份備援筆記 |
| `範例/` | 放你找來的版面圖和喜好卡 |
| `母版/` | AI 整理好的內容 |
| `產出/` | AI 做好的講義、學習地圖、簡報 |
| `版面喜好選單/` | 勾選你喜歡的版面 |
| `模板/` | 講義、學習地圖、簡報的模板 |
| `成品參考/` | 3 份做好的成品，可以打開來拆解 |
| `三層原理示意.html` | 60 秒的骨架、外觀、動作示意 |
