# AI 社團 HTML 課程

你準備自己的筆記，AI 幫你做成講義、學習地圖和簡報。不用會寫程式，也不用背語法。

## 下載入門包

1. 下載 [HTML講義入門包.zip](https://github.com/YuZhouLeo/Harness-Wiki-LLM/raw/main/HTML%E8%AC%9B%E7%BE%A9%E5%85%A5%E9%96%80%E5%8C%85.zip)。
2. 把 zip 解壓縮到桌面。不要直接在 zip 裡面開檔案。
3. 用瀏覽器打開 `HTML講義入門包/開始.html`。
4. 照 `開始.html` 的步驟安裝 VS Code 和擴充功能，再用自己的 AI 帳號登入。

### 用 Code 按鈕下載時

你也可以按這頁綠色的 **Code**，再按 **Download ZIP**。這個 zip 包含整門課，解壓縮後的資料夾叫 `Harness-Wiki-LLM-main`。

在 VS Code 要打開裡面的 `HTML講義入門包`，不要打開外層資料夾。打開外層資料夾時，AI 找不到 Skill 和規則檔。

## 這裡有什麼

| 檔案或資料夾 | 內容 | 什麼時候用 |
|---|---|---|
| `HTML講義入門包.zip` | 下面這個資料夾的壓縮檔 | 上課要用的檔，下載這個就夠了 |
| `HTML講義入門包/` | 操作說明、規則檔、5 個 Skill、模板、喜好選單、成品參考 | 想先在網頁上看裡面有什麼時 |
| `HTML課程簡報.html` | 上課用的簡報，共 43 張 | 複習。要連結打得開，整個 repo 要一起下載 |
| `課堂示範/` | 用入門包實跑一次的成果：母版、講義、學習地圖、簡報 | 想看做完長什麼樣子時 |
| `三層原理-示意影片.mp4`、`三層原理-示意.gif` | 60 秒的骨架、外觀、動作示意 | 複習原理 |
| `學習地圖-操作預告影片.mp4` | 學習地圖的操作預告 | 課前預告 |

GitHub 網頁只顯示 HTML 的原始碼。要看畫面，請下載後用 Chrome 或 Edge 打開。
